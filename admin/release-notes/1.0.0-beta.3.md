# KeepThyHeart Bible Desktop v1.0.0-beta.3

This is a beta release, so expect rough edges!  Problems and suggestions are welcome in the Issues tab, or through **Help > Give feedback** in the app.

## Upgrading from 1.0.0-beta.1 or 1.0.0-beta.2

**Please install this version by hand.** The in-app updater in beta.1 and beta.2 has a bug ("Cannot set properties of undefined (setting 'autoDownload')"), so **Download & Update** cannot update those copies. This release fixes it, and later updates will work in the app.

Your notes, highlights, bookmarks, settings and modules are kept.

- **Windows:** run the new installer.
- **Linux:** install the new `.deb` over the old one, or replace the AppImage.
- **macOS:** download the new `.dmg` and replace the app in Applications.

## What's new and changed

- **Download & Update works again** (the fix described above).
- **Preferences > Updates** shows the version, build and release channel (stable or beta), and has a **Check for updates** button that opens the same dialog as **Help > Check for Updates**.
- Optional **Check for updates at startup**, off unless you tick it. It only looks for a newer version and tells you; it never downloads or installs anything by itself, and it needs **Allow web requests**.
