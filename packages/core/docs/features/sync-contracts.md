# Sync contracts (living copy)

The interfaces of end-to-end encrypted sync (task 0063 design, built in task 0150). This is the branch's living copy of
the 0063 contracts: the code under `packages/core/src/Sync`, `packages/sync-server` and the hosts is the source of truth,
and this page records the shape and every change made while building it. Read the **Changes since 0063** list first;
the contract text below it is the original, with the superseded parts marked.

## Changes since 0063

- **Record ids (section 2):** `deriveRecordId` = first 16 bytes of `HMAC-SHA256(recordIdKey, "kth-recid-v1" 0x00 scope 0x00 key)`. The domain label is part of the MAC input and `scope` must not contain NUL.
- **Record envelope (section 3):** the AAD is `utf8("kth-rec-v1") || version (1 byte, = blob[0]) || accountId (16 B) || recordId (16 B) || u32be(epoch)`. The blob version byte is bound into the AAD so a later envelope version can never be replayed as v1.
- **Change tracking (section 4):** `sync_record` has a `rev` counter bumped by every local change. `markSynced(..., { expectRev })` clears `dirty` only if the row has not changed since it was read for the push (an edit made while the push is in flight stays dirty and is pushed next round); `DirtyRow.rev` carries the value. `touch(kind, localKey, { deleted? })` marks an arbitrary key dirty (adapters).
- **Codecs (section 5):** `CodecContext.report` is an optional sink for notes (unknown modules). `decode` throws `RecordDecodeError` for malformed payloads (the engine keeps the record opaque). Natural-key scopes: see the header of `packages/core/src/Sync/codecs/RecordCodec.ts`.
- **Merge (section 6):** `mergeOutcomeFor(type, local, remote, base, ctx)` is the entry point; a remote tombstone is passed as `{ d: {}, h: '', deleted: true }`, so a delete of unknown time never beats a concurrent edit. `conflictCopy` outcomes may carry `d` (merged winner). The note conflict link is `metadata.conflictOf`.
- **Server API (section 7):**
  - Signup does not reveal registered addresses: a signup for an existing address returns the same success shape and mails the owner (`conflict_email` is no longer returned by signup).
  - `ResetConfirmRequest` carries the new `accountId` (the wraps' AAD binds it); the server re-keys the account to it.
  - New routes: `POST resend-verification {email}` (always 204) and `PUT devices/current {nameSealed}`.
  - `KeysRequest` password-from-recovery also carries `recoveryAuthKey` + `wrappedAkRecovery` (the spent code is replaced in the same request).
  - Push body limit is 8 MiB, other bodies 64 KiB. The host must set Express `trust proxy` so rate limits use the real client IP.
- **Engine (section 8):** `SyncEngineOptions` gains `random`, `timers`, `debounceMs`, `onNeedNewEpoch`, `onApplied`, `pushLimits`; `SyncAdapter` gains `conflictCopy` and `merge`; `SyncEngine.reencryptAll()` re-seals everything under the current epoch after a key rotation. `syncNow` never rejects: failures go to the status store.
- **AccountClient (section 9):** typed `AccountError` codes; optional deps `wantToken`, `kdfCost`, `onUnlocked`, `onSignedOut`, `onWipe`; `needsReencrypt` / `consumeReencrypt()` after rotation or start-over.
- **Hosts:** the web server module is `apps/web/server/modules/accounts` (flag `accounts`, which requires `localUserDb`); the desktop IPC section (13) is replaced by the accounts feature module's `AccountsApi`; the UI components (14) live in `packages/ui/src/components/Account`.

## 1. `packages/core/src/Sync/types.ts` — shared primitives

```ts
import type { KdfParamsJson } from '../Crypto';

/** 16 random bytes as 32 lowercase hex chars. Account ids, record ids, device ids (device: 8 bytes / 16 hex). */
export type HexId = string;
export type AccountId = HexId;   // 32 hex, generated by the client at sign-up
export type RecordId = HexId;    // 32 hex; random, or derived (deriveRecordId) for natural-key records
export type DeviceId = string;   // 16 hex

/**
 * Hybrid logical clock, fixed width so string comparison == causal order:
 * `${ms 12 hex}:${counter 4 hex}:${deviceId 16 hex}` e.g. "0192f3a1b2c3:0000:9f3c0a1b2c3d4e5f".
 */
export type HlcString = string;

/** Record types. Core tables use their table name; extension and file records use these prefixes. */
export type RecordType =
  | 'user_commentary' | 'user_note' | 'note_verse_link' | 'content_verse_link' | 'verse_link'
  | 'user_text_markup' | 'user_cross_reference' | 'collection' | 'pinned_item'
  | 'reading_plan' | 'reading_plan_day' | 'reading_plan_passage' | 'user_reading_progress'
  | 'prayer_item' | 'prayer_update' | 'journal_entry' | 'user_data_item'
  | 'ext.kv' | 'ext.db' | 'bn.file';

/** Decrypted content of one record (the JSON inside the envelope, before padding). */
export interface RecordPlaintext {
  /** Record type. Unknown types MUST be kept opaque by readers, never dropped or deleted. */
  t: RecordType | string;
  /** Codec version of `d` for this type (starts at 1). A reader seeing a higher version keeps the record opaque. */
  cv: number;
  h: HlcString;
  /** Writing device. */
  dev: DeviceId;
  /** Type-specific payload; foreign keys are RecordIds, never local ids. */
  d: Record<string, unknown>;
}

/** What the server stores and returns per record. */
export interface EncryptedRecord {
  id: RecordId;
  seq: number;          // server-assigned, strictly increasing per account
  deleted: boolean;     // tombstone: blob is null
  blob: Uint8Array | null;
}

export type { KdfParamsJson };
```

import type { RandomSource } from '../../Crypto';
import type { RecordId, RecordPlaintext } from '../types';

/**
 * blob = 0x01 | u32be(epoch) | nonce(12) | AES-256-GCM(dataKey[epoch], padded, aad) (ct || tag16)
 * aad  = utf8("kth-rec-v1") || accountId(16 B) || recordId(16 B) || u32be(epoch)
 * padded = u32be(len(json)) || json || 0x00.. up to the next multiple of 1024 (json <= 64 KiB) or 16384 (larger)
 * Max plaintext json 1 MiB - 4 (RecordTooLargeError above).
 */
export const RECORD_BLOB_VERSION = 1;
export const MAX_RECORD_JSON = 1024 * 1024 - 4;

export class RecordTooLargeError extends Error {}
/** Blob version or epoch this client cannot read (keep the record opaque; do not treat as damage). */
export class UnknownEpochError extends Error {}

export interface RecordCipher {
  seal(id: RecordId, pt: RecordPlaintext): Promise<Uint8Array>;
  /** Throws AuthError on tamper/swap (AAD mismatch), UnknownEpochError, or SyntaxError for bad JSON. */
  open(id: RecordId, blob: Uint8Array): Promise<RecordPlaintext>;
  /** Count of seals under the current epoch this session; engine asks for a new epoch after 2^30. */
  readonly sealsThisEpoch: number;
}

export function createRecordCipher(u: UnlockedAccount, random?: RandomSource): RecordCipher;

CREATE TABLE IF NOT EXISTS sync_record (
  table_name   TEXT NOT NULL,        -- registry table, or 'ext.kv', 'ext.db:<extId>/<db>/<table>', 'bn.file'
  local_key    TEXT NOT NULL,        -- pk as text; composite pks joined with char(31)
  record_id    TEXT UNIQUE,          -- NULL until assigned (derived ids are assigned at push time)
  changed_ms   INTEGER NOT NULL,     -- wall ms of the last local change (set by triggers)
  hlc          TEXT,                 -- HLC of the version last pushed or applied
  server_seq   INTEGER,              -- seq of the server version this row is based on; NULL = never on server
  dirty        INTEGER NOT NULL DEFAULT 1,
  deleted      INTEGER NOT NULL DEFAULT 0,
  base_json    TEXT,                 -- RecordPlaintext.d as last synced (3-way merge base)
  PRIMARY KEY (table_name, local_key)
);
CREATE INDEX IF NOT EXISTS sync_record_dirty ON sync_record(dirty) WHERE dirty = 1;
CREATE TABLE IF NOT EXISTS sync_state   (key TEXT PRIMARY KEY, value TEXT NOT NULL);  -- keys below
CREATE TABLE IF NOT EXISTS sync_opaque  (record_id TEXT PRIMARY KEY, server_seq INTEGER NOT NULL, blob BLOB);
CREATE TABLE IF NOT EXISTS sync_pending (record_id TEXT PRIMARY KEY, server_seq INTEGER NOT NULL,
                                         plaintext TEXT NOT NULL, missing TEXT NOT NULL); -- child waiting for parent

// ChangeTracker.ts
import type { ISql } from '../../Data/Core/ISql';

export interface TrackedTable {
  table: string;                  // e.g. 'user_note'
  pk: string[];                   // from the registry
  kind: string;                   // sync_record.table_name value (normally === table)
}

export interface DirtyRow {
  kind: string; localKey: string; recordId: RecordId | null;
  changedMs: number; serverSeq: number | null; deleted: boolean; baseJson: string | null;
}

export interface ChangeTracker {
  /** Idempotent: create sync_* tables and AFTER INSERT/UPDATE/DELETE triggers for `tables`.
   *  Triggers do nothing while sync_state.applying = '1'. Existing rows are enrolled as dirty (first upload). */
  install(tables: TrackedTable[]): void;
  /** Drop triggers and sync_* tables (sign-out). Local user data is untouched. */
  uninstall(): void;
  dirty(limit: number): DirtyRow[];
  pendingCount(): number;
  /** After a successful push or an applied pull. */
  markSynced(kind: string, localKey: string, v: { recordId: RecordId; serverSeq: number; hlc: HlcString; baseJson: string | null; deleted: boolean }): void;
  assignRecordId(kind: string, localKey: string, recordId: RecordId): void;
  lookupByRecordId(recordId: RecordId): { kind: string; localKey: string; deleted: boolean; dirty: boolean; serverSeq: number | null; baseJson: string | null; hlc: HlcString | null } | undefined;
  lookupByLocal(kind: string, localKey: string): { recordId: RecordId | null } | undefined;
  /** Runs `fn` in one transaction with sync_state.applying = '1'; restores '0' even if fn throws (rollback). */
  applyRemote<T>(fn: () => T): T;
  state: { get(key: string): string | undefined; set(key: string, value: string): void };
  /** Store / list / delete undecodable records and children awaiting parents. */
  opaque: { put(id: RecordId, seq: number, blob: Uint8Array | null): void; all(): Array<{ id: RecordId; seq: number; blob: Uint8Array | null }>; remove(id: RecordId): void };
  pending: { put(id: RecordId, seq: number, pt: RecordPlaintext, missing: RecordId[]): void; all(): Array<{ id: RecordId; seq: number; pt: RecordPlaintext; missing: RecordId[] }>; remove(id: RecordId): void };
}

export function createChangeTracker(sql: ISql): ChangeTracker;
/** The tracked set for the user DB: every registry table with cls 'content', plus 'extension_storage' (kind 'ext.kv'). */
export function coreTrackedTables(): TrackedTable[];
