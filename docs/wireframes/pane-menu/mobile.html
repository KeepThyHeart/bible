  2. Commentary view (MobileCommentaryView): "..." sits at the end of the sticky back bar that names the open commentary, so it is always reachable while reading the entry. The commentary list (no single module open) shows no "...".

  5. The Study view (MobileStudyPane) mixes several modules (cross-references, topics, dictionary), so it gets no pane-level "..." in this proposal; each section could get its own later (open question 2).
