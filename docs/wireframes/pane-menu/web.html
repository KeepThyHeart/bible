John 3:16
For God so loved the world, ... These words are a continuation of Christ's discourse with Nicodemus, and contain the reason of the former, why the Son of man must be lifted up, and why whosoever believes in him shall not perish, but have eternal life; namely, because of the great love of God to the world...

Notes

  1. Bible pane: the "..." button is the last control of .bible-toolbar__right, after the chapter arrows, styled as a .bible-toolbar__btn. It acts on the active tab's translation.
  2. Commentary pane: the "..." sits at the end of .commentary-tab-bar, after "+". The tab bar stays put; the passage header scrolls with the content, so a menu there would scroll away.
  3. The drop-down reuses .verse-context-menu rows, so it matches the verse right-click menu. Module Info is first, with the module's short name on the right.
  4. Other items are only things the pane already offers: Copy verses... (opens the existing Copy dialog for the selected verse), Text size (the Aa stepper), More text options... (Settings, font section), and for commentary Pin / Unpin (the pin button).
  5. The existing toolbar buttons stay (open question 1). In this proposal the menu only adds a second route to them.
  6. Module Info is a .module-dialog sized to its content. It replaces the "About this commentary" expander at the foot of the commentary; that link would open this dialog instead.
  7. Fields: name, short name, type and language, description, copyright, license link, source, version, and the attribution line (0227 provenance.attribution). Empty fields are left out, as the expander does today.
  8. Sample data in these pages is illustrative.
